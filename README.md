# SmartLMS

Student library for Southeast University. This phase is **design only** — mock catalog, no database.

## Run

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## What’s in this preview

- Marketing site: home, features, stacks, plans, about, how it works
- Sign in / Sign up with **Scan ID card** camera mock
- Admin desk: overview, books, members, plans, payments
- English / বাংলা toggle
- Mobile bottom navigation

Postgres and real auth come later.
